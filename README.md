# NexaHub

A Cyberpunk Web Interface to Control Ollama + LM Studio AI Models.

## How to Run

1.  **Open `index.html`:** Simply open the `index.html` file in your web browser.
2.  **Use a Launcher (Optional):**
    *   **Windows:** Double-click `start_nexahub.bat`.
    *   **Linux/macOS:** Run `sh start_nexahub.sh` in your terminal.

## Features

*   Chat with local AI models from Ollama and LM Studio.
*   Customize the interface with different colors and effects.
*   Everything runs locally in your browser.

## Settings

*   Click the gear icon to open the settings panel.
*   Configure the URLs for your Ollama and LM Studio servers.
*   Scan for available models and select one to chat with.
*   Enable or disable UI animations and glow effects.
